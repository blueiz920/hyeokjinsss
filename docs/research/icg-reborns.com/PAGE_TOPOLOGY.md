# ICG Reborns project-end topology

Source: `https://www.icg-reborns.com/en/projects/icgreborns-portfolio`

This is an authorized design-reference extraction for a bounded portfolio component. It does not reproduce the source brand, copy, or assets.

1. Case-study outcome and metric cards
2. `section.wrap` containing `.next-proj`
   - left: eyebrow and large next-project link
   - right: rounded “Back to all work” link
3. `footer.footer.wrap`
   - large collaboration sentence
   - two navigation columns
   - copyright/typography bar

The source end section is static document flow on a dark surface. It has no sticky or fixed layer. Dividers separate the case study, next-project row, and footer. In the local adaptation the existing cream-to-black animated curve remains the only transition layer and the ICG hierarchy is assembled inside the existing `ProjectNext` footer.
